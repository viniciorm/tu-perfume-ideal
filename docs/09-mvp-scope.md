# MVP Scope

## Incluido en el MVP

- Landing principal.
- Buscador rápido.
- Catálogo filtrable.
- Guía tipo wizard.
- Resultados sugeridos.
- Productos destacados.
- Detalle de producto.
- Selección de productos.
- Resumen de pedido.
- Mensaje prellenado por WhatsApp.
- Link a Instagram.
- Tabla editable de precios.
- Catálogo editable desde archivo local.
- Configuración editable.
- Nota legal visible.
- Diseño mobile-first.
- Estados vacíos, carga y error.

## Fuera del MVP

No implementar:

- Login.
- Registro.
- Panel administrativo.
- Supabase.
- Base de datos.
- Pagos online.
- Stripe.
- Checkout.
- Control real de stock.
- Confirmación automática de pedidos.
- Emails.
- Make.
- n8n.
- Manychat.
- HubSpot.
- OpenAI.
- IA.
- Multiusuario.
- Roles y permisos.
- Dashboard administrativo.
- Analítica avanzada.
- Cupones.
- Fidelización.
- Integración con despacho.

## Regla de oro

Si una funcionalidad no ayuda directamente a que el usuario encuentre, seleccione y consulte perfumes por WhatsApp, queda fuera del MVP.
