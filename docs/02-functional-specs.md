# Functional Specs

## Flujo principal del usuario

1. El usuario entra desde Instagram, WhatsApp o link en bio.
2. Ve la landing principal.
3. Puede elegir entre:
   - Buscar por nombre.
   - Usar la guía de compra.
   - Navegar el catálogo.
4. Revisa productos.
5. Abre detalle de producto.
6. Selecciona uno o varios perfumes.
7. Ve resumen de selección.
8. Envía consulta o pedido por WhatsApp.

## Pantallas necesarias

### Home

Debe incluir:

- Header.
- Hero.
- CTA principal.
- Buscador rápido.
- Acceso a guía.
- Líneas de producto.
- Productos destacados.
- Cómo comprar.
- Preguntas frecuentes.
- Footer.

### Catálogo

Debe incluir:

- Buscador.
- Filtros.
- Grilla de productos.
- Estado vacío.
- Botón para limpiar filtros.
- Botón para consultar por WhatsApp.

### Guía de compra

Wizard paso a paso.

Preguntas:

1. ¿Para quién buscas el perfume?
2. ¿Qué tipo de aroma prefieres?
3. ¿Cuándo lo usarías?
4. ¿Qué intensidad buscas?
5. ¿Tienes un perfume de referencia?
6. ¿Qué formato prefieres?
7. Resultados sugeridos.

### Detalle de producto

Debe mostrar:

- Imagen.
- Código.
- Línea.
- Aroma inspirado en.
- Marca de referencia.
- Familia olfativa.
- Intensidad.
- Ocasión.
- Formato.
- Precio.
- Stock.
- Botón seleccionar.
- Botón consultar por WhatsApp.

### Resumen de selección

Debe mostrar:

- Productos seleccionados.
- Código.
- Nombre de referencia.
- Formato.
- Cantidad.
- Precio unitario.
- Total estimado.
- Botón “Enviar pedido por WhatsApp”.
- Botón “Limpiar selección”.

## Funcionalidades MVP

- Búsqueda por texto.
- Filtros por línea, género, familia, intensidad, formato y stock.
- Guía tipo wizard.
- Matching de productos.
- Selección múltiple.
- Cálculo de total estimado.
- Links de WhatsApp con mensajes prellenados.
- Catálogo local editable.
- Precios locales editables.

## Funcionalidades fuera del MVP

No implementar:

- Login.
- Registro.
- Panel administrador.
- Supabase.
- Base de datos.
- Pagos online.
- Stripe.
- Checkout.
- Control real de stock.
- Emails.
- Make.
- n8n.
- HubSpot.
- Manychat.
- IA.
