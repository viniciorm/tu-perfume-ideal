# Design System

## Estilo general

La app debe verse como una boutique digital de perfumes alternativos.

Debe ser:

- Elegante.
- Editorial.
- Aspiracional.
- Limpia.
- Premium accesible.
- Mobile-first.
- Clara y confiable.

## Inspiración visual

Tomar como referencia visual el catálogo Parfums 2026:

- Títulos grandes.
- Secciones ordenadas por líneas.
- Uso de códigos de fragancia.
- Familias olfativas.
- Mapas sensoriales.
- Mensaje emocional asociado a fragancias.

## Tipografía

Usar tipografía moderna, limpia y elegante.

Recomendación:

- Títulos: peso alto, estilo editorial.
- Textos: legibles, claros y cercanos.
- Botones: directos y visibles.

## Componentes visuales

Usar ShadCN/UI para:

- Button
- Card
- Badge
- Input
- Select
- Dialog
- Sheet
- Tabs
- Accordion
- Skeleton
- Progress
- Toast
- Radio Group
- Checkbox

## UX mobile

Prioridad absoluta en mobile.

Reglas:

- Botones grandes.
- Tarjetas fáciles de tocar.
- Filtros simples.
- Wizard de una pregunta por paso.
- CTA visibles.
- Resumen de selección claro.
- WhatsApp visible solo en momentos relevantes.

## Tono de comunicación

Cercano, claro y confiable.

Usar frases como:

- “Encuentra tu perfume alternativo ideal”
- “Busca por nombre o déjate guiar”
- “Selecciona tus favoritos y consulta por WhatsApp”
- “Aroma inspirado en”
- “Referencia olfativa”

Evitar:

- Decir que son perfumes originales.
- Usar nombres de marcas como si fueran productos oficiales.
- Prometer duración exacta.
- Sonar demasiado técnico.
