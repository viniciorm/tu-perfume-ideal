# Agent Skills

## Rol del agente

Actúa como un desarrollador senior frontend especializado en React, TypeScript, Vite, Tailwind CSS y ShadCN/UI.

Tu objetivo es construir una aplicación funcional, limpia, mobile-first y enfocada en conversión por WhatsApp.

## Reglas de trabajo

1. Leer primero `README.md`.
2. Luego leer los documentos en `/docs`.
3. Respetar estrictamente el alcance del MVP.
4. No agregar backend.
5. No agregar login.
6. No agregar Supabase.
7. No agregar pagos online.
8. No usar APIs externas.
9. Mantener los datos en archivos locales editables.
10. Priorizar mobile-first.

## Cómo tomar decisiones

Si hay ambigüedad, preferir:

- Simplicidad.
- Menor fricción para el usuario.
- Conversión por WhatsApp.
- Código fácil de editar.
- Componentes reutilizables.
- Diseño elegante y claro.

## Estilo de código

- Usar TypeScript.
- Usar componentes funcionales.
- Separar lógica y presentación.
- Mantener funciones puras en `/utils`.
- Usar nombres descriptivos.
- Evitar archivos gigantes.
- No duplicar lógica.

## Estilo visual

La app debe inspirarse en una boutique digital de perfumes:

- Azul profundo.
- Blanco.
- Dorado suave.
- Negro elegante.
- Tarjetas limpias.
- Jerarquía visual clara.
- Botones visibles.

## Restricciones legales

Nunca presentar los productos como perfumes originales.

Usar siempre:

- Aroma inspirado en.
- Referencia olfativa.
- Perfume alternativo.

Mostrar nota legal en Home, Footer, Detalle y FAQ.

## Criterio de éxito

La app es exitosa si un cliente puede entrar, encontrar un perfume, seleccionarlo y enviar un mensaje claro por WhatsApp en menos de 2 minutos.
